# 离线私钥保险箱

## 打开

双击同目录的 **离线私钥保险箱.html**，用浏览器打开。无需安装软件、注册账户或联网。页面需要启用 JavaScript，并需要浏览器支持本地文件的 Web Crypto 功能。

这是完全离线的文件工具，没有网站账户或服务器。建议第一次用无价值的测试文本完整走一遍保存和解密流程。

## 加密并保存

1. 在「加密文本」中输入或粘贴文字。
2. 点击「生成并下载新密钥」，保存 `.key` 文件。已有密钥可直接选择。
3. 点击「选择已保存的密钥文件」，重新选择刚下载的密钥。页面会检查是否与刚生成的密钥一致。
4. 点击「加密并下载网页」，保存 `加密保险箱-日期时间.html`。
5. 在出现的保存校验区域，选择刚下载的加密网页。页面会核对完整网页并尝试解密；显示「保存校验通过」后，当前输入和密钥会被清除。如果你在导出后又修改了文本，新内容会保留，并提示它尚未加密。
6. 将密钥移到单独的离线介质，例如 U 盘，并另做一份离线备份。加密网页与密钥不要一起保存到同一个云盘。

如果浏览器询问是否允许保存文件，请允许本次下载。页面的「已发起下载」不表示文件已成功落盘，必须完成第 5 步校验。保存时不要覆盖其他有用的文件。换了密钥之后，旧文件仍需要原来的密钥。

## 以后如何解密

只需保留以下两份文件：

- **加密保险箱-日期时间.html**：包含密文和解密界面。
- **保险箱密钥-编号.key**：你的独立密钥。

双击加密网页 → 选择对应的 `.key` 文件 → 点击「使用密钥解密」→ 点击「显示原文」。整个过程不需要原来的工具网页、Mac 应用、命令行工具或联网服务。

你也可以打开工具网页的「解密文件」页面，选择加密网页和密钥。此方式只解析导入文件的数据区，不执行其内部脚本。

换电脑后，在支持本地 Web Crypto 的浏览器中使用相同文件和密钥即可。不要使用浏览器的“另存为网页”来制作加密文件；请使用工具内的「加密并下载网页」按钮。

## 使用边界

- **密钥丢失，无法恢复。** 工具没有后门或找回功能。任何同时持有密钥和加密网页的人都能解密。
- 随机密钥为 256 位，使用 AES-256-GCM。正确实现、随机源正常且密钥未泄露时，目前公开技术无法在现实可行的计算量内通过穷举恢复原文。没有任何自制工具能保证绝对安全；本版本完成了功能和互操作测试，未经独立专业安全审计。
- **只打开自己导出或确认可信的 HTML。** HTML 自带可执行代码；如果被别人替换，可能在你选择密钥时窃取密钥。GCM 检测的是密文篡改，不能证明整个网页程序可信。工具内「解密文件」入口只读取数据，不运行导入文件的代码。
- 电脑中毒、浏览器扩展、屏幕录制、键盘记录、剪贴板管理器或泄露的密钥，均可能绕过对磁盘密文的保护。加密不改变钱包或区块链本身的安全性。
- 切换窗口会隐藏解密结果；5 分钟无操作会清除当前页面的文本和密钥引用。未导出的文本也会被清除。没有自动草稿或会话恢复。
- 文本复制由你自行选取并复制。页面不管理系统剪贴板，不能清除第三方剪贴板历史；也不能保证浏览器内存或系统交换文件的彻底擦除。
- 单次文本最多 1 MiB，支持中文、表情、换行和空格。加密文件长度会透露大致原文长度，不包含原文明文标题或钱包地址。
- 浏览器负责保存文件，页面无法控制下载目录的磁盘权限。请保护你的系统账户，注意系统云同步和备份位置。

## 已验证环境

本机 macOS 26.5.1、Google Chrome，直接使用 `file://` 打开，测试浏览器网络设为离线。已验证工具网页与导出的自解密网页。

同时检查了 390 像素窄屏布局与 200% 字体放大，未出现横向溢出。窄屏检查不等同于手机系统实测。Windows、Linux、Safari 和 Firefox 尚未在本次交付中实测；不保证所有浏览器版本支持本地文件加密。

## 校验与源代码

随附「源代码与测试.zip」包含源码、构建脚本、功能测试和公开格式说明。日常使用不需要解压或运行它。校验文件可用于检查自己保存的可信原件是否意外改变；若校验文件本身也被替换，则不能证明来源可信。

依据：[NIST AES 标准](https://www.nist.gov/publications/advanced-encryption-standard-aes)、[NIST GCM 标准](https://www.nist.gov/publications/recommendation-block-cipher-modes-operation-galoiscounter-mode-gcm-and-gmac)、[W3C Web Crypto](https://www.w3.org/TR/WebCryptoAPI/)。这些链接只是文档参考，工具运行不访问它们。
