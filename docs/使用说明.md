# 私钥保险箱使用说明

## 打开工具

访问 https://userinner.github.io/offline-private-key-vault/ ，或用浏览器打开下载好的「离线私钥保险箱.html」。在线访问会从 GitHub 加载工具；文本与密钥始终在浏览器本地处理。离线使用时需要保留工具页面。

## 加密文本

1. 输入或粘贴需要保密的文字。
2. 点击「生成并下载新密钥」，保存 `.key` 文件；已有密钥也可以直接选择。
3. 在「选择已保存的密钥文件」中，重新选择刚下载的密钥。
4. 点击「加密并下载文件」，得到 `加密保险箱-日期时间.vault`。
5. 选择刚下载的 `.vault` 文件，完成保存校验。校验通过后会清除当前文本和密钥；如果导出后又编辑了新文本，则保留新内容并提示它尚未加密。
6. 将 `.vault` 和 `.key` 分开存放，并另做离线备份。

「已发起下载」不代表保存成功，请完成第 5 步。不要覆盖其他有用文件。

## 解密：文件 + 密钥

1. 打开工具，点击「解密文件」。
2. 选择之前下载的 `.vault` 加密文件。
3. 选择对应的 `.key` 密钥文件。
4. 点击「使用密钥解密」，成功后点击「显示原文」。

`.vault` 是独立密文文件，不是网页，不包含密钥或解密程序。需要通过工具读取它，不能靠双击文件直接显示原文。文件格式公开，不绑定原电脑或账户，兼容实现也可以用正确密钥解密。

**旧版兼容：** 如果你此前导出过 `.html` 加密文件，也可以在解密区选中它。工具只读取其中的密文，不执行导入网页的代码。

## 保管和边界

- **密钥丢失无法恢复。** 没有后门或找回功能。同时拥有密文和密钥的人可以解密。
- 密钥是系统安全随机源生成的 256 位数据，采用 AES-256-GCM。正确实现且密钥未泄露时，以当前公开技术对随机密钥穷举在现实中不可行。本工具未经独立专业安全审计，不承诺绝对安全。
- 请使用可信的工具页面。已控制的系统、恶意浏览器扩展、键盘记录、屏幕录制或泄露的密钥不在加密保护范围内。
- 切换窗口会隐藏原文；5 分钟无操作会清除当前文本和密钥，包括尚未导出的输入。页面不保存草稿。
- 文字复制由你自行选取；页面不管理系统剪贴板，无法保证清除第三方历史、浏览器内存或系统交换文件。
- 单次文本最多 1 MiB，支持中文、表情、换行、空格和前导 U+FEFF。文件长度会透露大致原文长度。
- 浏览器负责保存文件，页面无法设置磁盘文件权限。保护好系统账户，注意下载目录是否被云同步。

## 验证环境

已在本机 macOS 26.5.1、Chrome 152.0.7977.84 测试。覆盖本地工具文件、独立 `.vault` 导出、密钥重新选择、保存校验、错误密钥、密文篡改、旧版 HTML 导入与自动清除。

Windows、Linux、Safari、Firefox 和手机系统尚未在本次交付中实测。窄屏布局检查不等同于手机实测。

源代码及公开格式见 GitHub 仓库 https://github.com/userInner/offline-private-key-vault 。日常使用无需运行源码或测试。
