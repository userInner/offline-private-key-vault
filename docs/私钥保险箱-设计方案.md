# 私钥保险箱：文件 + 密钥

按用户最新要求，网页仅作为加密和解密的操作工具。文本加密后保存为独立 `.vault` 文件；解密时在网页中选择 `.vault` 与 `.key`，不再将解密程序封装到输出文件中。

## 格式与安全

沿用原有 AES-256-GCM 格式：8 字节 `PVLT0001` 认证头、12 字节随机 nonce、密文与 16 字节认证标签。文本为 UTF-8，大小 1 字节至 1 MiB。密钥文件为 `PKEY0001` 加 32 字节系统随机生成的密钥。

随机源正常、实现正确且密钥未泄露时，以当前公开技术穷举在现实中不可行。工具未经独立专业安全审计，不能防止已控制的电脑窃取明文或密钥。

## 操作与文件验证

生成新密钥后要求重新选择已保存的文件。下载 `.vault` 前执行解密比对；保存后再选择落盘文件，进行全文件逐字节比对及解密验证。校验成功后清除当前文本与密钥；导出后新增的编辑会保留，避免数据丢失。

解密先校验格式和长度，再认证 AES-GCM 标签，最后允许显示文本。结果默认隐藏，失焦自动隐藏，5 分钟无操作清除敏感状态。异步操作使用状态版本避免清除后回填旧内容。

## 兼容与本地处理

保留旧版 HTML 数据导入，只解析唯一的 Base64 密文数据区，永不执行导入文件内的脚本。新文件直接保存原始二进制密文，不包含网页、密钥或程序。

工具页面可在线访问或下载后离线打开。加密解密不发送网络请求，不使用浏览器持久存储、第三方脚本或服务器。使用者应保留可信的工具副本，以便长期离线恢复。格式公开，不绑定设备或账户。
