# 离线私钥保险箱：最终设计

日期：2026-09-15。按用户最终确认，交付形式为离线网页。

## 用户目标

把 Web3 私钥、助记词或任意文本加密保存。解密依赖独立密钥，不绑定原电脑、账户、服务器或桌面软件；不需要另外保留或安装解密工具。

## 交付

- 一个独立 HTML 工具：输入文本、生成或选择密钥、导出自带解密界面的加密网页，也可导入已有加密网页并解密。
- 中文使用说明、公开文件格式和源代码/测试压缩包。
- 不部署网站，不创建账户或服务。运行时无第三方依赖、远程资源或网络请求。

## 使用流程

1. 输入文本，生成并下载随机密钥，或选择已有密钥。
2. 重新选择已保存的新密钥；对应校验通过才允许加密。
3. 下载自带解密功能的 HTML 文件。
4. 选择刚下载的文件，逐字核对完整网页内容，再尝试解密。校验成功才报告保存校验通过；若输入没有新修改则清除当前文本和密钥，若有新修改则保留并提示尚未加密。
5. 以后只需用兼容浏览器双击该加密网页，选择独立密钥即可解密，无需原来的工具文件。
6. 密钥与密文分开保管，并另做离线备份。密钥丢失无法找回。

## 加密与公开格式

Web Crypto 的 AES-256-GCM，系统安全随机源生成 32 字节密钥，每次加密生成新的 12 字节随机 nonce，使用完整 16 字节认证标签。

- 密钥文件：ASCII `PKEY0001` + 32 字节原始密钥，共 40 字节。
- 密文：ASCII `PVLT0001` + 12 字节 nonce + 密文 + 16 字节标签。
- 认证附加数据恰为 `PVLT0001`，文本为 UTF-8，限制为 1 字节至 1 MiB。
- HTML 以标准 Base64 在固定惰性数据区承载密文，保留固定界面和解密代码；不嵌入密钥或明文。
- 任何遵循格式的 AES-GCM 实现均可独立解密，不需要硬件或账户信息。密码算法不自行设计。

## 安全与界面

解密认证成功后原文仍默认隐藏。切换窗口隐藏结果；5 分钟无操作清除当前敏感内容；支持立即清除。用户自行选中文字复制，不自动管理剪贴板。不存草稿、浏览器存储或会话。

导出采用用户交互前捕获的固定模板，只替换密文数据区，避免把页面中的输入意外写入文件。工具导入其他 HTML 时仅解析数据，不执行脚本。异步操作通过状态版本防止清除后重新填回旧密钥或原文。CSP 限定内嵌程序和样式的哈希，并禁止网络连接和外部资源。

自解密 HTML 是可执行文件，其网页程序不由密文认证标签保护。必须使用自己导出或确认可信的原件；不能把 GCM 密文完整性误称为整份网页的可信验证。

## 安全目标的准确表述

在算法实现正确、随机源正常、密钥未泄露的前提下，以目前公开技术对随机 256 位密钥穷举在现实中不可行。不承诺绝对不可破解；本工具不是经独立专业安全审计的产品。被控制的系统、恶意扩展、键盘记录、屏幕录制和泄露的密钥均在此保护范围之外。

浏览器无法保证彻底擦除内存、系统交换文件或第三方剪贴板历史，也无法设置下载文件的磁盘权限。系统云同步仍可能同步用户选择的下载目录。

## 验收范围

核心测试覆盖 Unicode、前导 U+FEFF、空白、1 MiB 边界、错误密钥、逐字节篡改、截断、尾随数据、非法格式和随机 nonce；Node 独立 AES-GCM 实现与网页实现双向互操作。

实际浏览器以离线模式直接打开本地文件，验证密钥下载与重新选择、导出与重新打开、完整保存校验、不清除新修改文本、错误密钥与密文篡改拒绝、原文文本显示、隐藏/清除、超时清除和异步取消。视觉检查覆盖桌面和窄屏；平台实测范围详见使用说明与验证记录。
