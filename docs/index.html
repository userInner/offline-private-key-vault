安全与使用说明

密钥由系统安全随机源生成，采用 AES-256-GCM 加密并检测密文篡改。正确实现且密钥未泄露时，以目前公开技术，穷举在现实中不可行；这不代表电脑中毒后也能保护明文。

请使用可信的工具页面。导出的 .vault 文件只包含密文，不含密钥或解密程序。也可导入旧版 .html 加密文件，页面仅读取其中的密文，不执行它的代码。

建议断网使用，并将密钥另存到 U 盘、再做离线备份。不要将两份文件一起同步到云盘。5 分钟无操作会清除当前敏感内容；浏览器内存、系统交换文件和剪贴板历史无法保证彻底擦除。

请使用支持本地文件 Web Crypto 的现代浏览器。下载是由浏览器保存的，页面无法设置磁盘文件权限；请使用你自己的系统账户保护下载目录。文件格式与解密代码公开，不绑定账户或原电脑。
